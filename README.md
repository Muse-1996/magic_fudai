# magic_fudai
抖音福袋挂机APP，无需电脑，只需手机即可运行。



本应用采用ADB方案运行，非[无障碍方案]；本应用开发初衷是抽鱼竿的，如果刚好您也是钓鱼爱好者，也欢迎体验我的另一款作品【微信小程序-知钓】。

### 使用说明：
1. 安装程序，只支持Android
2. 设置中开启开发者模式，设备需连接WiFi
3. 打开程序，进行[无线调试]连接（在无线调试内，点击使用配对码配对设备，出现配对码弹层后，下拉通知，输入配对码）
4. 开启悬浮窗、后台运行权限
5. 打开悬浮球
6. 进入抖音直播，点击悬浮球，开始任务

### 注意：
1. 请自行查找本手机开启开发者模式的方式
2. 挂机过程中，手动操作有可能导致任务流程失败
